2. Mathematical Boundary & Target Calculation

At 09:20:00 IST, ATM CE and ATM PE contracts are locked from the NIFTY spot price. Each option's 09:15–09:20 close price establishes fixed breakout boundaries for the entire session:

For ATM CE:
CE Reference = 09:15–09:20 CE Close
CE Upper (+0.9%) = CE Reference × 1.009
CE Lower (-0.9%) = CE Reference × 0.991

For ATM PE (Completely Independent):
PE Reference = 09:15–09:20 PE Close
PE Upper (+0.9%) = PE Reference × 1.009
PE Lower (-0.9%) = PE Reference × 0.991
Crucial Target Anchoring Principle: Targets are strictly computed from the Actual Entry Fill Price, NOT the morning reference level.
• Target 1 = actual_entry_fill_price + ₹20.00
• Target 2 = actual_entry_fill_price + ₹40.00
This guarantees real-world fill prices, slippage, and bid-ask spreads are accurately accounted for.
